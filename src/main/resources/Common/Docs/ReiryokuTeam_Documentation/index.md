# Bleach Reiryoku

Welcome to Bleach: Reiryoku. An unofficial fan-made Bleach mod. 
This mod is planned to be a large-scale Bleach ARPG. Various elements are yet still to be added.


Right now this mod includes armors as well as various weapons. The weapons included are mostly from the **Shinigami Faction** (_Zanpakuto_).
